1. Click a panel to edit it. Box: drag. Text: click, type (IME/Japanese fine), Enter commits.
2. Select: click picks one (generous hit area). Drag empty space = marquee multi-select. Shift+click adds/removes. Drag any selected item moves the whole group. Del removes all selected.
3. Single selection shows 8 Photoshop-style handles — sides stretch one axis, corners scale evenly, for both boxes and text. Resizing a box edge snaps it to other boxes with a pink guide. Opacity slider fades selected items (100 = solid); Font box sets text size.
4. Each state zooms independently for fine alignment: Zoom−/+ buttons or Ctrl++ / Ctrl+− (Ctrl+0 resets), 50–100%. Load BG… puts your game screenshot under every panel for tracing (fit-to-width, undistorted) — BG: on/off toggles, slider fades it. Boxes draw on top.
5. Draw order inside a panel = z-order (monster, action, item, weapon). Battle template fills the active panel. Save all downloads every labeled state (BG is reference-only, not saved).
6. Forward/Backward nudges selected items one layer, To Front/To Back jumps them (Ctrl+] / Ctrl+[, +Shift for jump). The fill checkbox sets new-box fill and recolors selected boxes.
7. Copy (Ctrl+C) / cut (Ctrl+X) / Paste (Ctrl+V) clones exact boxes+text into the active state — click another panel, paste, same sizing, same spot. Repeat pastes cascade +16px.
8. Undo (Ctrl+Z) / Redo (Ctrl+Y) covers draw, move, resize, delete, paste, reorder, fill, and state ops.
9. Dragging a box shows a pink guide when its edges line up with another box's edges — and it sticks, so you can slide along the aligned edge without losing it. Hold Alt (or Ctrl) while dragging/resizing to suspend snapping and place freely. Text never triggers guides. Align L/C/R/T/M/B lines up 2+ selected items exactly.
10. Item panel below: every box/text carries slot (top/monster/party/action/item/weapon), z (layer above wins: Z0 base, Z1 action, Z2 item, Z3 weapon) and a note. Label things — slot+z ship inside the saved SVG so nothing is guessed. Click a row to select it. With Link: on, labeling a box pushes slot+z to the same box in every state (same size / same text — label once in state 1, states 2-4 remember); Sync all labels catches up work you already did. Later states win conflicts; Ctrl+Z undoes a sync.
